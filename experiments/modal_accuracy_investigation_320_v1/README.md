# Investigating deterministic opinion accuracy

The user requested further investigation toward approximately 95% accuracy after changing to a deterministic target. The target is the source's most probable next single-response opinion, A iff `p(A)>0.5`, on **all** existing updates. This differs from the sampled majority outcome and from generating fresh trajectories with deterministic agents. The earlier 91.4% sampling reference does not cap this target.

Use the existing 320 training /80 validation MATH/Llama conversations. Development and candidate selection use the established internal 256/64 question split. All final models freeze before scoring the reused outer80, which remain exploratory. The 40 reserved assessment questions are not loaded. Next-state probabilities are labels only. No source calls are made.

## Hypothesis journal

1. **The compact state omits useful source priors or history.** Add current probabilities, initial probabilities, initial population state, causal history, lexical features and ordered argument PCA. Six fixed tree recipes screen these additions on internal64. Accuracy spans 87.75–87.95%; initial probabilities and larger text PCA do not resolve the gap. Each tree is refitted on320 at its internally selected duration. Naive corrections using previous prediction residuals also worsened training accuracy; these are diagnostic training-only results, not validation scores.
2. **The probability loss does not match deterministic classification.** Compare source-probability targets with hard modal targets, selecting both by internal mode accuracy then mode-label NLL. Test 978-parameter current-state and 986-parameter initial-state transformers, then 14,946-parameter richer choice/argument models. Internal results remain roughly 87–88%. There are16 tuning fits,24 three-seed refits and four22/25-coefficient Ising baselines.
3. **Separately encoded or compressed arguments lose their relation to the question.** Frozen MiniLM now encodes Question/Options/Message together, with complete token windows. Compare PCA32 with full384 vectors and matched question-plus-A/B controls:14,946 and26,210 update parameters. Eight tuning fits and12 refits are planned. Joint encoding of80,989 texts took600seconds. This changes text context without exposing answer keys or future messages.
4. **The frozen sentence encoder is unsuitable for the prediction task.** An internal-only pilot will continue the selected full-vector argument head for three epochs, either retaining the frozen encoder or adapting its last layer at two rates. Embeddings and the first five layers stay frozen. Promote only if internal accuracy improves by at least0.5percentage points over the starting head. No outer80 scoring is used for this decision.
5. **Earlier responses reveal question-specific behavior missing from the instantaneous state.** A16-unit GRU summarizes each agent's observed probability/opinion history and friendly/unfriendly means, up to the current round. An identical2306-parameter control sees only round numbers. Cross this with ordered choice/argument tokens. Two rates and three refit seeds use the same internal selection policy. Future observations are zeroed before the model sees them, and a regression check verifies that modifying future data cannot change inputs.
6. **Early stopping conceals fitting capacity.** Matched 215,426-parameter choice/argument models train without dropout or weight decay. On eight training questions, the argument model reaches 100% and the choice model 99.95%. On 256 training questions, terminal accuracy reaches 99.05% /98.30%, while internal holdout accuracy falls to 80.36% /82.37%. These are diagnostic terminal fits, not final selected models. Neither crosses the prespecified 89% internal promotion gate.
7. **Fixed sentence averaging hides informative words.** Retain every frozen MiniLM token representation, reduce it to PCA32 using only sampled training texts, and fit a small token projection followed by uniform or learned attention pooling. Compare choice and argument inputs, with 4,706 /4,738 update parameters. Fixed extra fields identify message region, uppercase A/B, digits and token position. Token encoding retains all 13.63 million tokens and takes 156 seconds on MPS; no source LLM calls are made.
8. **The complete observed population reveals shared question context.** Append all 32 current opinions and current/previous/cumulative probabilities to two state trees. Internal gains are 0.000 /0.079 pp, below the +0.5 pp promotion gate. These models are not scored on outer80. Population information is a predictive proxy, not a causal claim about nonneighbors.
9. **Token attention is nearly uniform because its keys have small variance.** A training-only probe on two questions finds normalized attention entropy 0.999997. Normalize keys without adding affine parameters, and separately restrict pooling to message words. Those words still receive question/options context during frozen encoding. The one-token A/B control removes its 32 inactive query parameters. Four conditions use the same token data, selection policy and three-seed refits.

Implementation failures were caught before outer scoring: an end-of-fit logging import in cycle2, a pre-training text tensor dtype mismatch in cycle3, and GPU memory exhaustion during the first encoder epoch in cycle4. Failed attempts and original code/protocols are archived separately. No failed fitted models enter comparisons. Encoding/PCA for cycle3 are reused only after every stored hash is verified; their computation was unaffected by the dtype fix. Cycle4 restarts all arms with four-graph batches,32-token-sequence batches,32 warmup updates and fixed padded shape buckets; the normal GPU memory limit remains enabled. A real training-batch regression check supplements the synthetic tests. An earlier CPU-only encoder start was deliberately interrupted before any encoder arm completed, then all arms restarted on the GPU.

All new artifacts are under `runs/modal_accuracy_investigation_320_v1/`. Previous experiment code, fitted weights and source data remain unchanged. The independent HPC3 collection is not controlled by this experiment.

## Interpretation rules

Report mean individual-model accuracy over three refit seeds, not a best seed or an ensemble. Pair uncertainty by whole question. A95% claim requires approximately95% overall mode accuracy across all80 validation questions; confidence-based filtering, target-derived features and calling the source model at prediction time do not satisfy that goal. Frozen MiniLM's22,713,216 pretrained parameters are additional to update-rule counts. If encoder weights are adapted, report them as trainable.
